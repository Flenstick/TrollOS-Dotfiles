# Обновления TrollOS

## У тех, кто поставил TrollOS

- Оболочка сама проверяет репозиторий, из которого её поставили, раз в день (через 90 с после входа, потом каждые 6 ч,
  если прошли сутки) и присылает уведомление «Доступно обновление TrollOS». Сама ничего не ставит.
- **Настройки → Обновления → Обновить**: `git pull`, снимок конфигов в `~/.local/state/angelos/backups/<дата>-update`
  и установщик в режиме умного обновления (`UPDATE_FROM`):
  - трогаются **только файлы, которые изменились в обновлении**, всё остальное у человека остаётся как есть;
  - файл, который человек не правил, просто заменяется новым;
  - файл, который он правил, **сливается** с новой версией (трёхстороннее слияние, как в git) — его правки остаются;
  - если слить не вышло (поменяли одни и те же строки) — остаётся его файл, новая версия ложится рядом как
    `*.trollos-new`, а в Настройках появляется список таких файлов;
  - файлы, которые обновление удалило, удаляются, только если человек их не трогал;
  - пакеты, SDDM и службы обновление не трогает.
- **Откатить обновление** — кнопка там же: конфиги возвращаются из снимка, репозиторий — на прошлый коммит, а то,
  что было до отката, сохраняется в `…-before-rollback`. Хранятся пять последних снимков.
- Из терминала: `bash ~/.config/quickshell/angelos/scripts/dotfiles-update.sh --check|--last|--rollback <repo>`.

## Автору (выложить новую версию)

Твоя система — источник: правишь у себя, потом выкладываешь.

```sh
cd ~/Projects/TrollOS-Dotfiles
scripts/trollos/publish.sh                    # перенести и показать, что изменится
scripts/trollos/publish.sh "Док: новые иконки" # перенести, проверить, закоммитить и отправить
```

- Берётся `~/.config/quickshell/angelos` и то, что перечислено в `scripts/trollos/publish.list`
  (плагины из `~/.config/angelos/plugins`, скрипты из `~/.local/bin`). Чего нет в списке — остаётся только у тебя.
- Перед коммитом каждая добавленная строка проверяется на путь к твоему дому и на строки из
  `~/.config/trollos/private.txt` (Discord ID, почта, имя телефона…). Нашлось — коммита не будет.
- Конфиги niri, терминалов и GTK в репозитории — шаблоны (`@HOME@`), их правь прямо в репозитории.
- Сообщение коммита увидят люди в «Что нового» — пиши его по-русски и понятно.

## Обновления angelOS (оригинал)

```sh
scripts/trollos/upstream.sh          # сколько нового у MixaDoDs
scripts/trollos/upstream.sh merge    # влить в TrollOS
```

После слияния проверь части TrollOS (логотип, `Config.qml`, `dotfiles-update.sh`, `install.sh`, README),
запусти у себя, потом `git push origin trollos`.
